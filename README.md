# くらしのナビ｜プレビュー版

このリポジトリは、くらしのナビのスマートフォン実機テスト用です。

- 本番サイト・本番リポジトリには変更を加えません。
- テスト用ブランチ: `preview/kurashi-navi-v5`
- 公開内容は確認用の試作版です。情報は必ず各公式窓口で確認してください。
- テスト時の不具合は、画面のスクリーンショット・選んだ項目・操作手順を添えて共有してください。

## テスト対象
退去費用、通販返品、退職手続き、家賃値上げ、近隣騒音、不明請求、サブスク解約、失業給付、住所変更、水漏れ、ガス漏れ、ガスコンロ点火不良。

## 注意
ガス臭い・ガス漏れの疑いがある場合は、火気や電気スイッチに触れず、屋外へ避難してガス事業者へ連絡してください。
