WORK & RETIREMENT GUIDE

退職前後のよくある困りごと

退職日はいつにするか、有給休暇や必要書類はどうするか。状況ごとに確認するポイントと相談先をまとめました。

最終確認日：2026年11月11日｜公的機関・公式情報をもとに作成

先に確認しておきたいこと

  • 雇用契約書・就業規則と雇用形態（無期・有期）
  • 退職希望日、最終出勤日、有給休暇の残日数
  • 給与締日・支給日、賞与規程、次の勤務先の入社日
  • 健康保険・厚生年金・雇用保険の手続き

1. 退職日はいつにするのがいい？

一律に「月末が得」「月途中が得」とは言えません。社会保険料、次の勤務先の入社日、給与締日、有給休暇、賞与の支給条件を合わせて考えます。

月末退職と月途中退職の違い

  • 月末退職：退職日の翌日（翌月1日）に健康保険・厚生年金の資格を喪失します。原則として退職月分まで会社の社会保険料が発生し、最後の給与から前月分と退職月分の2か月分が控除される場合があります。
  • 月途中退職：退職日の翌日に資格を喪失し、会社の社会保険料は原則として前月分までです。ただし、その後の健康保険（国民健康保険・任意継続・家族の扶養等）と年金の切替が必要になり、保険料負担がなくなるわけではありません。

例えば3月30日退職なら資格喪失日は3月31日、3月31日退職なら4月1日です。退職後すぐに再就職する場合は、新しい会社の社会保険資格取得日との間に空白ができないか確認してください。

退職日を決める前のチェック

  1. 給与の締日・支給日と、退職月の給与計算方法を人事・給与担当に確認する。
  2. 賞与の支給日在籍要件と、退職予定者への支給規程を確認する。賞与は会社規程・支給条件によって異なります。
  3. 有給休暇の残日数と、最終出勤日・退職日を整理する。
  4. 次の勤務先の入社日、健康保険・厚生年金の資格取得日を確認する。
  5. 退職後に国民健康保険・国民年金へ切り替える場合の手続きと保険料を市区町村等に確認する。

結論：社会保険料だけで退職日を決めず、退職後の保険料や次の勤務先の加入日まで含めて比較してください。個別の金額は会社の給与担当、加入している健康保険、年金事務所、市区町村に確認するのが確実です。

2. 退職前に有給休暇を消化したい

退職日までに残っている年次有給休暇を取得することは可能です。退職日を過ぎてから有給休暇を取得することはできません。

  1. 給与明細・勤怠システム等で有給休暇の残日数を確認する。
  2. 退職日と最終出勤日を分けて考え、残日数を踏まえた取得希望日を会社へ申請する。
  3. 申請日・残日数・会社とのやり取りを記録しておく。
  4. 取得を拒まれたり不利益な扱いを受けたりした場合は、労働局や労働基準監督署に相談する。

会社には一定の場合に時季変更権がありますが、退職日を越えて取得時季を変更することはできません。引き継ぎは有給取得前に調整しておくと円滑です。

3. 退職後の書類が届かない

失業給付の手続きで必要な離職票、転職先に提出する源泉徴収票、健康保険の切替に使う資格喪失証明書など、書類ごとに発行元・用途が異なります。

  1. 必要な書類と用途を整理し、退職した会社の人事・総務へ発行状況と発送予定日を問い合わせる。
  2. 離職票が届かない場合は、住所地を管轄するハローワークへ相談する。
  3. 源泉徴収票が届かない場合は、まず会社へ請求し、解決しなければ税務署へ相談する。
  4. 健康保険の資格喪失証明書は、会社または加入していた健康保険者に発行方法を確認する。

会社への連絡日、担当者、回答、必要書類を記録しておきましょう。

4. 最後の給料や残業代が支払われない

未払いの給与・残業代があるときは、まず勤務実績と給与計算の根拠を整理します。

  1. 雇用契約書、給与明細、勤怠記録、シフト表、タイムカード、業務連絡などを保存する。
  2. 未払い期間・金額・計算根拠を整理し、会社へ書面やメールで支払いを求める。
  3. 解決しない場合、労働基準監督署へ相談する。労働条件や個別紛争の相談は総合労働相談コーナーも利用できます。

残業代は労働時間や割増率、管理監督者該当性などで判断が変わります。自分だけで断定せず、記録を持って相談してください。

5. パワハラ・職場環境が原因で辞めたい

心身の安全を優先してください。退職するかどうかを急いで決める前に、相談・休職・労災などの選択肢も確認できます。

  1. 日時、場所、言動、同席者、業務への影響を具体的に記録する。
  2. メール・チャット・業務指示など、適法に保有できる資料を保存する。
  3. 社内窓口、人事、都道府県労働局の総合労働相談コーナーへ相談する。
  4. 体調に影響が出ている場合は医療機関へ相談し、診断書や受診記録を保管する。

身の危険がある場合は相手と直接対峙せず、安全確保を優先してください。総合労働相談コーナーは無料・予約不要で、いじめ・嫌がらせ・パワハラ等の相談を受け付けています。

6. 離職票の退職理由が実際と違う

離職票の離職理由が実際と異なる場合、内容に同意できないことをハローワークへ伝え、事実を示す資料を提出できます。

  1. 離職票の離職理由欄を確認し、事実と異なる箇所を整理する。
  2. 退職勧奨のメール、解雇通知、契約書、勤務記録、会社とのやり取りなどを保存する。
  3. 雇用保険の受給手続き時に、住所地を管轄するハローワークへ異議と事情を伝える。
  4. ハローワークが本人・会社双方の主張と資料を確認して離職理由を判定する。

会社の記載だけで最終決定するわけではありません。離職票を受け取ったら、早めに内容を確認してください。

7. 退職金が支払われない・金額が違う

退職金は、法律上一律に全ての会社へ支給が義務付けられているものではありません。会社に退職金制度がある場合は、就業規則・退職金規程・雇用契約などで支給条件を確認します。

  1. 就業規則・退職金規程で対象者、勤続年数、支給率、支払時期を確認する。
  2. 自分の勤続年数・退職理由・計算基礎と会社の計算を照合する。
  3. 不明点は会社へ計算内訳と支払予定日を文書で確認する。
  4. 規程と異なる扱いが疑われる場合は、労働局の総合労働相談コーナーや弁護士等へ相談する。

退職金制度の有無・内容は会社によって異なります。規程の記載と個別の合意を確認することが出発点です。

8. 体調不良で退職・休職を考えている

体調不良がある場合、退職だけでなく、休職制度や傷病手当金、労災の対象になる可能性も含めて確認しましょう。

  1. 医療機関に相談し、就労の可否や必要な療養期間について確認する。
  2. 会社の休職制度、休職中の給与・社会保険料、復職条件を就業規則で確認する。
  3. 業務外の病気やけがで働けず給与が十分に支払われない場合、加入する健康保険の傷病手当金を確認する。
  4. 退職後も傷病手当金を継続して受けるには、退職前の被保険者期間や退職日時点の受給要件など条件があるため、退職日を決める前に保険者へ確認する。
  5. 業務や通勤が原因の病気・けがが疑われる場合は、健康保険ではなく労災保険の相談先を確認する。

傷病手当金は、退職すれば自動的に受け取れるものではありません。特に退職日に出勤した場合など、継続給付の要件に影響することがあります。退職前に加入先の健康保険者へ確認してください。
