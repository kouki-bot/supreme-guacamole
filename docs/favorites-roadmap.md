# お気に入り機能：今後の拡張方針

## 現在の仕様（2026-11-08）
- お気に入りはブラウザの localStorage に保存する。
- 保存データは `schemaVersion: 1` を持つ。
- 保存数はアプリ側で固定上限を設けない（ブラウザ側の保存容量には依存）。
- 現時点でアカウント登録、サーバー保存、端末間同期、課金は実装しない。
- 端末変更・ブラウザ変更・閲覧データ削除などで保存内容が引き継がれない可能性を画面とプライバシーポリシーで案内する。

## 将来の有料価値として検討する機能
1. 無料：この端末・ブラウザ内のお気に入り保存。
2. 有料候補：アカウントに紐づくクラウド保存と複数端末同期。
3. 追加候補：保存データのバックアップ・復元、家族との共有。

## 実装時の原則
- ローカル保存を利用するだけのユーザーに、アカウント登録を強制しない。
- 課金開始前に、無料範囲・有料範囲・解約後のデータ扱いを明示する。
- 決済を実装する場合は、決済事業者の公式APIとサーバー側で契約状態を検証する。フロントエンドだけで有料判定しない。
- クラウド同期を実装する場合は、ログイン、アクセス制御、削除・退会時のデータ削除、バックアップ、障害時の復旧方針を先に設計する。
- 利用者の需要と継続率を確認してから有料化する。現段階では課金導線を表示しない。
